Лабораторная работа №1: Введение в Java

Описание

Данная лабораторная работа посвящена изучению базовых возможностей языка Java.
В ходе выполнения работы были реализованы простые консольные программы, демонстрирующие работу с методами, циклами, строками и условиями.

Ключевые концепции

System.out.println() — вывод информации в консоль

    Метод main() — точка входа в программу

    Циклы for — перебор данных и повторение операций

    Методы — разделение логики программы на отдельные функции

    String — работа со строками

    Условные операторы — проверка условий выполнения

Задания:

1 Программа Hello World

        Создана первая Java-программа, выводящая строку "Hello World" в консоль.

        Изучена структура Java-программы и работа метода main().

2 Проверка строки на палиндром

        Реализована программа для проверки строк на палиндром.

        Создан метод reverseString() для переворота строки.

        Создан метод isPalindrome() для сравнения строки с её перевернутой версией.

        Аргументы передаются через командную строку.

3 Поиск простых чисел

        Реализована программа для поиска всех простых чисел меньше 100.

        Создан метод isPrime() для проверки числа на простоту.

        Для проверки используются циклы и операция остатка от деления.
