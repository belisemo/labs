# Лабораторная работа №5: Регулярные выражения в Java

## Описание

Данная лабораторная работа посвящена изучению регулярных выражений (Regular Expressions) в языке Java.

В ходе выполнения работы были реализованы программы для поиска, проверки и обработки текстовых данных с использованием классов `Pattern` и `Matcher` из пакета `java.util.regex`.

Работа демонстрирует применение регулярных выражений для поиска чисел в тексте, проверки паролей и IP-адресов, обработки строк и поиска слов по заданному шаблону.



## Используемые технологии

* Java
* Regular Expressions (Regex)
* Pattern
* Matcher
* Обработка исключений (`try-catch`)



## Задание 1. Поиск всех чисел в тексте

Реализована программа `NumberFinder`, которая находит все целые и дробные числа в строке.

### Используемое регулярное выражение


\\b\\d+(\\.\\d+)?\\b


### Возможности

* Поиск целых чисел
* Поиск дробных чисел
* Обработка ошибок при работе с регулярными выражениями

### Пример результата

28




## Задание 2. Проверка корректности пароля

Реализована программа `PasswordCheck`, которая проверяет пароль на соответствие следующим требованиям:

* длина от 8 до 16 символов;
* содержит хотя бы одну заглавную букву;
* содержит хотя бы одну цифру;
* состоит только из латинских букв и цифр.

### Используемое регулярное выражение


^(?=.*[A-Z])(?=.*\\d)[A-Za-z\\d]{8,16}$


### Пример результата


Пароль корректный




## Задание 3. Поиск заглавной буквы после строчной

Реализована программа `LowerUpper`, которая находит случаи, когда сразу после строчной буквы следует заглавная.

Найденные сочетания выделяются символами `!`.

### Используемое регулярное выражение


[a-z][A-Z]


### Пример результата


!aB!c1!eD! !aB!!BB!cc!cD!




## Задание 4. Проверка корректности IP-адреса

Реализована программа `IpCheck`, которая проверяет корректность IPv4-адреса.

### Проверки

* адрес состоит из четырёх чисел;
* числа разделены точками;
* каждое число находится в диапазоне от 0 до 255.

### Пример результата


IP корректный




## Задание 5. Поиск слов, начинающихся с заданной буквы

Реализована программа `WordFinder`, которая находит все слова, начинающиеся на указанную букву.

Поиск выполняется без учёта регистра символов благодаря использованию флага:


Pattern.CASE_INSENSITIVE


### Используемое регулярное выражение


\\b + letter + \\w*\\b


### Пример результата

Для строки:

tung tung TUng sahur


и буквы:


t


получаем:


tung
tung
TUng

## Основные понятия

### Pattern

Класс для компиляции регулярного выражения.


Pattern pattern = Pattern.compile(regex);


### Matcher

Класс для поиска совпадений в тексте.

Matcher matcher = pattern.matcher(text);


### find()

Поиск всех совпадений.


matcher.find();


### matches()

Проверка полного соответствия строки шаблону.


matcher.matches();


### replaceAll()

Замена всех найденных совпадений.


matcher.replaceAll("...");
