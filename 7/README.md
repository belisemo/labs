# Лабораторная работа №7: Многопоточность в Java

## Описание

Данная лабораторная работа посвящена изучению многопоточности в языке программирования Java.

В ходе выполнения работы были реализованы программы для:

* параллельного вычисления суммы элементов массива;
* поиска максимального элемента матрицы;
* моделирования работы склада с несколькими грузчиками.

В работе продемонстрированы основные возможности многопоточного программирования, включая использование пула потоков `ExecutorService`, интерфейса `Callable`, объектов `Future`, а также механизмов синхронизации `ReentrantLock` и `Condition`.

---

## Ключевые концепции

* **Thread** — выполнение кода в отдельном потоке.
* **Многопоточность** — параллельное выполнение нескольких задач.
* **ExecutorService** — управление пулом потоков.
* **Callable** — задача, возвращающая результат.
* **Future** — получение результата выполнения задачи.
* **ReentrantLock** — механизм блокировки для синхронизации потоков.
* **Condition** — ожидание и уведомление потоков.
* **await()** — перевод потока в режим ожидания.
* **signalAll()** — пробуждение ожидающих потоков.

# Задание 1. Параллельное вычисление суммы массива

## Описание

Реализована программа для вычисления суммы элементов массива с использованием пула потоков.

## Реализация

* Создаётся массив из 10000 элементов.
* Массив заполняется значением 1.
* Создаётся пул из 4 потоков с помощью `ExecutorService`.
* Массив разбивается на равные части.
* Каждая часть обрабатывается отдельной задачей `Callable`.
* Частичные результаты возвращаются через объекты `Future`.
* После завершения всех задач результаты суммируются в главном потоке.

## Используемые технологии

* ExecutorService
* Callable
* Future

# Задание 2. Поиск максимального элемента матрицы

## Описание

Реализована программа для поиска максимального элемента матрицы с использованием пула потоков.

## Реализация

* Создаётся двумерный массив (матрица).
* Для каждой строки матрицы создаётся отдельная задача `Callable`.
* Каждая задача находит максимальный элемент своей строки.
* Задачи выполняются в пуле потоков.
* Результаты собираются через объекты `Future`.
* После завершения вычислений определяется глобальный максимум матрицы.

## Используемые технологии

* ExecutorService
* Callable
* Future

# Задание 3. Моделирование работы склада

## Описание

Реализована многопоточная модель склада, на котором одновременно работают три грузчика.

Каждый товар имеет свой вес. Грузчики могут одновременно загружать товары в машину, однако суммарный вес груза не должен превышать 150 кг.

После достижения лимита машина отправляется на разгрузку и после возвращения процесс продолжается.

## Реализация

* Создан класс `Product`, описывающий товар.
* Создан класс `WarehouseManager`, управляющий процессом загрузки и разгрузки.
* Используется список товаров склада.
* Создаются три потока-грузчика.
* Создаётся отдельный поток для разгрузки машины.
* Для синхронизации используется `ReentrantLock`.
* Для организации ожидания и уведомления используются объекты `Condition`.
* При достижении лимита веса загрузка приостанавливается до завершения разгрузки.

## Используемые технологии

* ReentrantLock
* Condition
* await()
* signalAll()

---

# Работа программы

Программа демонстрирует:

* параллельное выполнение вычислений;
* распределение задач между потоками;
* получение результатов из нескольких потоков;
* синхронизацию доступа к общим ресурсам;
* взаимодействие потоков через механизмы блокировок и условий ожидания.
