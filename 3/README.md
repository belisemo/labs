# Лабораторная работа №3: Хэш-таблицы в Java

## Описание

Данная лабораторная работа посвящена изучению структуры данных хэш-таблиц и их реализации на языке Java.

В ходе выполнения работы была реализована собственная обобщенная хэш-таблица с использованием метода цепочек для разрешения коллизий, а также система учета заказов в ресторане на основе встроенного класса HashMap.

Программа демонстрирует основные операции работы с хэш-таблицами: добавление, поиск, обновление и удаление элементов.



## Ключевые концепции

* **HashTable** — структура данных для хранения пар «ключ-значение».
* **HashMap** — встроенная реализация хэш-таблицы в Java.
* **Коллизия** — ситуация, когда разные ключи попадают в одну ячейку таблицы.
* **Метод цепочек** — способ разрешения коллизий с использованием связанных списков.
* **LinkedList** — связанный список для хранения элементов при коллизиях.
* **Generics (обобщения)** — механизм создания универсальных классов и методов.
* **Collection Framework** — набор коллекций и алгоритмов Java.



## Задание 1. Реализация собственной хэш-таблицы

Создан обобщенный класс `HashTable<K, V>`.

Реализованы следующие возможности:

* хранение данных в виде массива связанных списков;
* вычисление индекса с помощью хэш-функции;
* добавление элементов методом `put()`;
* поиск элементов методом `get()`;
* удаление элементов методом `remove()`;
* подсчет количества элементов методом `size()`;
* проверка таблицы на пустоту методом `isEmpty()`;
* разрешение коллизий методом цепочек.



## Задание 2. Работа со встроенным классом HashMap

Реализована система хранения заказов ресторана.

### Класс Order

Содержит информацию о заказе:

* список заказанных блюд;
* общая стоимость заказа;
* время оформления заказа;
* статус заказа.

Реализованы методы:

* изменение статуса заказа;
* получение статуса;
* вывод информации о заказе.

### Класс OrderTracker

Использует структуру данных `HashMap<Integer, Order>` для хранения заказов.

Ключом является номер столика.

Значением является объект класса `Order`.

Реализованы операции:

* добавление заказа;
* поиск заказа по номеру столика;
* удаление заказа;
* изменение статуса заказа;
* вывод всех заказов.


## Структура проекта

### HashTable.java

Реализация собственной хэш-таблицы с использованием метода цепочек.

### Order.java

Класс, описывающий заказ ресторана.

### OrderTracker.java

Класс для управления заказами через HashMap.

### Main.java

Точка входа в программу и демонстрация работы всех функций.



## Демонстрация работы программы

В программе создаются несколько заказов ресторана.

Выполняются следующие действия:

1. Добавление заказов.
2. Вывод всех заказов.
3. Поиск заказа по номеру столика.
4. Изменение статуса заказа.
5. Удаление заказа.
6. Повторный вывод оставшихся заказов.
