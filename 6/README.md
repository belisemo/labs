# Лабораторная работа №6: Коллекции и дженерики в Java

## Описание

Данная лабораторная работа посвящена изучению коллекций, дженериков и структур данных в Java.

В ходе выполнения работы были реализованы:

* программа для подсчета наиболее часто встречающихся слов в текстовом файле;
* собственная реализация обобщенного стека (Stack);
* система учета продаж товаров с использованием потокобезопасной коллекции.

Работа демонстрирует использование коллекций HashMap, List, CopyOnWriteArrayList, а также применение Generics и сортировки данных.

---

## Используемые технологии

* Java Collections Framework
* HashMap
* ArrayList
* CopyOnWriteArrayList
* Generics
* Comparator
* Работа с файлами (File, Scanner)
* Сортировка коллекций

---

## Задание 1. Подсчет самых частых слов в тексте

Реализован класс `TopWords`.

### Возможности программы

* чтение текста из файла;
* приведение слов к нижнему регистру;
* удаление знаков пунктуации;
* подсчет количества повторений каждого слова;
* сортировка слов по частоте встречаемости;
* вывод 10 самых популярных слов.

### Используемые коллекции

* `HashMap<String, Integer>` — хранение слова и количества его повторений;
* `ArrayList<Map.Entry<String, Integer>>` — сортировка результатов.

## Задание 2. Реализация обобщенного класса Stack

Реализован собственный класс `Stack<T>` с использованием Generics.

### Реализованные методы

* `push(T element)` — добавление элемента в стек;
* `pop()` — удаление верхнего элемента;
* `peek()` — просмотр верхнего элемента без удаления.

### Особенности

* используется массив для хранения данных;
* реализована проверка переполнения;
* реализована проверка пустого стека;
* поддерживается работа с любым типом данных благодаря Generics.

### Демонстрация

В классе `Main` показана работа методов стека.

## Задание 3. Система учета продаж

Реализован класс `Shop`.

### Возможности программы

* хранение списка продаж;
* подсчет количества продаж каждого товара;
* поиск наиболее популярного товара;
* подсчет общей суммы продаж;
* вывод списка проданных товаров.

### Используемые коллекции

* `CopyOnWriteArrayList<String>` — хранение продаж;
* `HashMap<String, Integer>` — хранение цен товаров;
* `HashMap<String, Integer>` — подсчет количества продаж.

## Основные изученные темы

### Collections Framework

Набор готовых структур данных для хранения и обработки информации.

### HashMap

Коллекция вида:

Ключ → Значение

Используется для быстрого поиска и хранения данных.

### CopyOnWriteArrayList

Потокобезопасная реализация списка.

При изменении списка создается новая копия массива, что обеспечивает безопасную работу при одновременном чтении данных несколькими потоками.

### Generics

Механизм обобщенных типов данных.

Позволяет создавать универсальные классы и методы, работающие с различными типами данных.

### Comparator

Используется для задания собственного правила сортировки элементов коллекции.
