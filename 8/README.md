# Лабораторная работа №8: Аннотации, Stream API и многопоточность в Java

## Описание

Данная лабораторная работа посвящена изучению аннотаций, Stream API, Reflection API и многопоточной обработки данных в Java.

В ходе выполнения работы реализована система обработки текстовых данных с использованием пользовательской аннотации `@DataProcessor`, механизма Reflection API, Stream API и класса `ExecutorService`.

Программа считывает данные из файла, автоматически находит методы обработки данных, применяет их к входным данным и сохраняет результат в новый файл.

---

## Ключевые концепции

### Annotation

Аннотации используются для добавления метаданных к элементам программы.

В работе реализована пользовательская аннотация:

```java
@DataProcessor
```

которая используется для пометки методов обработки данных.

### Reflection API

Reflection API позволяет получать информацию о классах и методах во время выполнения программы.

В данной работе Reflection используется для поиска методов, помеченных аннотацией `@DataProcessor`, и их автоматического вызова.

### Stream API

Stream API используется для обработки коллекций данных в функциональном стиле.

В программе используются операции:

* `filter()` — фильтрация данных;
* `map()` — преобразование данных;
* `collect()` — сбор результата в список;
* `parallelStream()` — параллельная обработка данных.

### ExecutorService

`ExecutorService` используется для выполнения задач в отдельном потоке.

Обработка данных выполняется асинхронно через механизм `Future`.

## Реализованные классы

### DataProcessor

Пользовательская аннотация для пометки методов обработки данных.

```java
@DataProcessor
```

---

### FilterProcessor

Класс фильтрации данных.

Метод:

```java
filterShortWords()
```

оставляет только строки длиной более 3 символов.

---

### TransformProcessor

Класс преобразования данных.

Метод:

```java
toUpperCase()
```

переводит строки в верхний регистр и выводит информацию о потоке, выполняющем обработку.

---

### DataManager

Главный управляющий класс программы.

Основные функции:

* регистрация обработчиков данных;
* загрузка данных из файла;
* поиск методов с аннотацией `@DataProcessor`;
* запуск обработки данных через Reflection API;
* сохранение результата в файл.

---

### Main

Точка входа в программу.

Выполняет:

1. Создание входного файла `input.txt`;
2. Создание объекта `DataManager`;
3. Регистрацию обработчиков данных;
4. Загрузку данных;
5. Обработку данных;
6. Сохранение результата;
7. Вывод результата на экран.

---

## Алгоритм работы программы

1. Создать входной файл с тестовыми данными.
2. Создать объект `DataManager`.
3. Зарегистрировать обработчики данных.
4. Загрузить данные из файла `input.txt`.
5. Создать параллельный поток данных через `parallelStream()`.
6. Найти методы, помеченные аннотацией `@DataProcessor`.
7. Выполнить фильтрацию строк.
8. Выполнить преобразование строк в верхний регистр.
9. Собрать результат в список.
10. Сохранить результат в файл `output.txt`.
11. Вывести обработанные данные на экран.

## Пример работы программы

### Входные данные

```text
goida
aboba
dog
dexter
kiwi
mgr
```

### Выходные данные

```text
GOIDA
ABOBA
DEXTER
KIWI
```

Слова `dog` и `mgr` удаляются, так как их длина меньше либо равна 3 символам.
