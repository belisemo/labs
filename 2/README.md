Данная лабораторная работа посвящена изучению основных принципов объектно-ориентированного программирования на языке Java.

В ходе выполнения работы была реализована иерархия классов велосипедов с использованием абстракции, наследования, инкапсуляции, полиморфизма и переопределения методов.

Программа демонстрирует создание объектов различных классов, работу конструкторов, геттеров и сеттеров, а также использование статических полей и методов.

Ключевые концепции

Абстракция — создание базового абстрактного класса Bicycle.

Наследование — расширение классов Bicycle → MountainBike, KidsBike, BMX.

Инкапсуляция — использование модификаторов доступа, геттеров и сеттеров.

Полиморфизм — переопределение метода showInfo() в дочерних классах.

Переопределение методов (Override) — реализация собственного метода showInfo() в каждом наследнике.

Static — использование статического счетчика созданных объектов.

Задания
1. Создание абстрактного класса Bicycle
Создан базовый абстрактный класс Bicycle.
Класс содержит поля:
бренд велосипеда (brand);
тип велосипеда (type);
вес велосипеда (weight).
Реализованы конструкторы.
Реализованы геттеры и сеттеры.
Добавлен статический счетчик объектов count.
Добавлен абстрактный метод showInfo().
2. Реализация класса MountainBike
Создан класс MountainBike, наследующий Bicycle.
Добавлены поля:
тип подвески (suspension);
количество передач (gears).
Реализован конструктор с параметрами и конструктор по умолчанию.
Переопределен метод showInfo().
Добавлен метод ride().
3. Реализация класса KidsBike
Создан класс KidsBike, наследующий Bicycle.
Добавлены поля:
наличие дополнительных колес (dopWheels);
размер колес (wheelSize).
Переопределен метод showInfo().
Добавлен метод ride().
4. Реализация класса BMX
Создан класс BMX, наследующий Bicycle.
Добавлены поля:
наличие пегов (pegs);
размер колес (wheelSize).
Переопределен метод showInfo().
Добавлен метод doTrick() для выполнения трюков.
5. Демонстрация работы программы
Созданы объекты классов MountainBike, KidsBike и BMX.
Продемонстрирована работа конструкторов.
Продемонстрирована работа геттера и сеттера для поля brand.
Выполнен вывод информации о каждом объекте через метод showInfo().
Проверена работа статического счетчика объектов.
