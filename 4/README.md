# Лабораторная работа №4: Обработка исключений в Java

## Описание

Данная лабораторная работа посвящена изучению механизма обработки исключений в языке программирования Java.

В ходе выполнения работы были реализованы программы для:

* обработки ошибок при работе с массивами;
* копирования данных из одного файла в другой;
* создания и использования собственных исключений;
* логирования информации об ошибках в текстовый файл.

Работа демонстрирует использование конструкций `try-catch-finally`, создание пользовательских классов исключений, работу с файловыми потоками и средствами логирования Java.

---

## Ключевые концепции

### Exception

Механизм обработки ошибок и нестандартных ситуаций во время выполнения программы.

### try-catch-finally

Конструкция для перехвата и обработки исключений.

### Custom Exception

Создание собственных классов исключений для более точной обработки ошибок.

### FileInputStream и FileOutputStream

Потоки для чтения и записи данных в файлы.

### Logger

Средство логирования событий и ошибок приложения.

### IOException

Исключение, возникающее при ошибках ввода-вывода.

## Выполненные задания

### 1. Вычисление среднего арифметического элементов массива

Создана программа `ArrayAverage.java`, которая:

* обрабатывает массив строк;
* преобразует элементы массива в целые числа;
* вычисляет сумму и среднее арифметическое;
* обрабатывает исключение `NumberFormatException`, если элемент массива не является числом;
* обрабатывает исключение `ArrayIndexOutOfBoundsException` при выходе за пределы массива;
* использует блок `finally` для вывода результата вычислений.

Пример массива:


String[] arr = {"10", "20", "abc", "30"};




### 2. Копирование содержимого файла

Создана программа `FileCopy.java`, которая:

* открывает исходный файл для чтения;
* создаёт файл назначения;
* копирует данные побайтно;
* обрабатывает ошибки чтения и записи через `IOException`;
* корректно закрывает файловые потоки в блоке `finally`.

Используемые классы:


FileInputStream
FileOutputStream




### 3. Создание пользовательского исключения

Создан класс:

CustomNumberFormatException


Программа `NumberValidator.java`:

* проверяет возможность преобразования строки в число;
* использует метод `Integer.parseInt()`;
* при возникновении `NumberFormatException` создаёт и выбрасывает собственное исключение `CustomNumberFormatException`;
* записывает информацию об ошибках в файл журнала `errors.log`;
* использует классы `Logger`, `FileHandler` и `SimpleFormatter`.

Пример некорректного значения:


String value = "123j";
